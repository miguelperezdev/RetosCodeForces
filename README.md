# Retos Codeforces

Repositorio personal dedicado a la resolución de problemas de programación competitiva en **Codeforces**, utilizando **C++**.

Este repositorio funciona como un registro de aprendizaje y progreso, con soluciones organizadas según el rating de cada problema.

## Objetivos

* Mejorar la lógica y resolución de problemas.
* Fortalecer el dominio de C++.
* Practicar algoritmos y estructuras de datos.
* Aprender y reconocer patrones de resolución.
* Aumentar progresivamente la dificultad de los problemas.
* Mantener un historial organizado de las soluciones.

## Tecnologías

* **Lenguaje:** C++
* **Estándar:** C++17
* **Plataforma:** Codeforces
* **Control de versiones:** Git / GitHub

## Estructura

Los problemas están organizados según su rating en Codeforces.

```text
RetosCodeForces/
│
├── 800/
│   └── 4A_Watermelon/
│       └── main.cpp
│
├── 900/
│   └── ...
│
├── 1000/
│   └── ...
│
└── README.md
```

Cada problema contiene su solución en un archivo `main.cpp`.

## Convención de nombres

Las carpetas utilizan el siguiente formato:

```text
<problem_id>_<problem_name>
```

Ejemplo:

```text
4A_Watermelon
71A_Way_Too_Long_Words
231A_Team
```

## Commits

Los commits relacionados con soluciones utilizan la siguiente convención:

```text
solve: <problem_id> <problem_name>
```

Ejemplo:

```text
solve: 4A Watermelon
```

## Compilación

Las soluciones pueden compilarse utilizando `g++`:

```bash
g++ -std=c++17 -O2 -Wall -Wextra main.cpp -o main
```

Para ejecutar:

```bash
./main
```

## Progreso

El repositorio irá creciendo progresivamente a medida que se resuelvan nuevos problemas y aumente la dificultad.
